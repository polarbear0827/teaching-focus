## Final prompt

Use case: logo-brand. Asset type: macOS application icon for a teaching spotlight and screen drawing tool. Create ONE polished square 1024x1024 app icon, with a genuinely transparent exterior around a generously rounded dark midnight-blue squircle tile. Primary subject: a playful, rounded chunky white mouse-cursor arrow character with two tiny friendly black eyes, sitting inside a luminous cyan circular spotlight ring, one small coral-red sweeping drawing stroke accent. Style direction: friendly, quirky, rounded toy-like 3D illustration, restrained soft clay material, clean bold silhouette, premium macOS icon quality. Centered composition with generous padding, immediately legible at 32px. Cyan ring has a delicate controlled fluorescent glow against navy, not excessive bloom. The cursor is the dominant subject, no hands, no extra characters. Absolutely NO letters, NO words, NO numbers, NO typography, NO watermark. No presentation mockup, no grids, no variants, just the single icon. This is an original playful direction for the user's YEYE-branded tool; no specific reference art was supplied.

Original PNG preserved as AppIcon.png. The macOS iconset is mechanically resized using sips and packed with iconutil into AppIcon.icns. No design edits during conversion.
